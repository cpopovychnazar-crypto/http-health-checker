# HTTP URL Health Checker

Практична робота №1.

## Опис

Програма на Go перевіряє доступність HTTP-ресурсів та виводить:

- URL ресурсу;
- HTTP статус-код;
- текст статусу;
- час виконання запиту;
- повідомлення про помилку, якщо ресурс недоступний.

У програмі використовується інтерфейс `HealthChecker`, структура `HealthResult` та HTTP-клієнт з таймаутом.

## Вимоги

- Go 1.22 або новіше.
